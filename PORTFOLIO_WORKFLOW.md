# Portfolio Publishing Workflow

## For every new project
1. Add 3–8 strong images under `images/<project>/`.
2. Add the project object to `projects.js`.
3. Add a case-study section when the project deserves a full story.
4. Use: Context → Challenge → Concept → Execution → Outcome.
5. Only publish metrics and business results that can be substantiated.
6. Confirm that company/client images are permitted for public portfolio use.
