# Abhishek Anand — Portfolio Website

This is a ready-to-deploy static portfolio website.

## Quickest deployment
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel or Netlify.
3. Deploy with no build command and the project root as the site root.

## Add future work
Open `projects.js` and add another object to the `projects` array.

Example:
{
  title: "Project Name",
  brand: "Brand",
  year: "2027",
  category: "Store Experience",
  description: "Short case-study introduction.",
  tags: ["VM","Retail","NSO"],
  image: "images/project-name.jpg"
}

Create an `images` folder and put project images there.

## Before public launch
- Replace the portrait placeholder with a professional photograph.
- Add a professional email address.
- Add LinkedIn URL.
- Validate all career dates and portfolio metrics.
- Replace placeholder projects with actual case studies.
- Add the final CV PDF.
- Consider using a contact form rather than publishing personal phone numbers.
